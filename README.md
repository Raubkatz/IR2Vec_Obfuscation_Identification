This repository hosts a streamlined machine learning workflow aimed at classifying Tigress-obfuscated LLVM IR. It includes a CSV with IR2Vec-based embeddings of obfuscated programs and Python scripts for training, hyperparameter tuning, and evaluating CatBoost and ExtraTrees classifiers. By running the provided scripts, users can reproduce the reported performance metrics, inspect confusion matrices, and explore how each obfuscation type is recognized by the models.
